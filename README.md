# AttackOnFinger

**AttackOnFinger** is a Global Game Jam 2025 project developed in Unreal Engine. The game is inspired by the theme **"Bubble"** and presents a unique and chaotic third-person experience.

## Game Overview
In **AttackOnFinger**, players control a bubble-character in a vibrant, action-packed environment. The character's body is made entirely of bubbles, and enemies or environmental hazards can attack the player. Every hit destroys a bubble from the body, progressively decapitating body parts until the head is reached. Players must strategically avoid attacks while navigating the levels and making use of the environment to survive.
[GlobalGameJamSite](https://globalgamejam.org/games/2025/attack-finger-2)

The game combines **third-person action mechanics** with a playful, destructive bubble theme, offering a fresh take on health and damage systems where visual feedback directly shows the player's condition.

## Key Features
- Third-person bubble character gameplay
- Progressive destruction of body parts on attack
- Unique visual feedback system for damage
- Fast-paced, chaotic action in line with the "Bubble" theme
- Designed and built during **Global Game Jam 2025**

## How to Play
- Move your bubble character using standard WASD/Joystick controls.
- Avoid attacks and hazards to prevent your bubbles from popping.
- Survive as long as possible while exploring the interactive environment.

## Game Jam
This project was created for **Global Game Jam 2025**, showcasing creativity under the "Bubble" theme with rapid prototyping and teamwork.
